feat(ext): Elsevier 正文改为「后台取字节 + Blob 保存」（0.9.9）

用户提供的地址证明了截获是对的：
  https://pdf.sciencedirectassets.com/271097/.../main.pdf?X-Amz-Security-Token=...
但用 downloads API 下载这个签名地址返回的是 HTML —— 该地址对浏览器导航放行，
对扩展的下载请求不放行。

改为不依赖服务器的保存方式：
- 后台 fetch 预签名地址（扩展有 host 权限，不受跨域限制）取到字节
- base64 传给 offscreen 文档生成 Blob URL（Service Worker 没有
  URL.createObjectURL，且 sendMessage 会把 ArrayBuffer 序列化成 {}，必须走 base64）
- 用下载器保存该 Blob URL：Blob 下载完全本地，服务器校验拦不到
- 失败则回退到页面内 fetch + Blob，再失败才直接下载
- 每一步的结果写入 elsTrace

修复：offscreen.js 的 onMessage 监听器缺 sendResponse 参数（导致永久等待）。

验证：Nature 正文 3.17MB 经此路径保存为 %PDF-；完整回归 3 个文件全部 %PDF-，
popup 无报错。
